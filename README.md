# RaiderBuddy

**The Ultimate Companion App for ARC Raiders**

RaiderBuddy is a desktop utility application designed to enhance your ARC Raiders experience. Track events, plan builds, explore interactive maps, and dominate the competition.

![Event Timers](screenshots/events.png)

## ✨ Features

- **Event Timers** - Real-time countdowns for in-game events with map filtering and overlay support
- **Interactive Maps** - Detailed maps for all 5 locations with loot spots, extraction points, and enemy spawns
- **Skill Tree Planner** - Theory-craft and share your builds before spending points in-game
- **Tier List Maker** - Create and share weapon tier lists with drag-and-drop ease
- **In-Game Overlay** - View event timers on-screen while playing with hotkey toggle
- **Weekly Trials Guides** - Optimal routes, spawn locations, and strategies for weekly objectives
